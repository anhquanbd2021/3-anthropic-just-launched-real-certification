Blueprint guide

Reading a certification as market data

The Claude Certified Architect — Foundations exam (proctored, 60 MCQ / 120 min, 4-of-6 scenarios, scaled 100–1000, pass at 720, 12-month validity) publishes its blueprint. This page maps each lab to the signal it makes legible.

Unofficial summary. Domain weights and scenario names reflect the public exam guide. This lab is educational and not affiliated with Anthropic.

Start here

What this demo proves

A vendor blueprint is a dataset: the weights are the vendor's bet on what the job consists of. Agentic Architecture & Orchestration at 27% outranks every "know the model" domain — and the out-of-scope list (fine-tuning, tokenization, model-parameter trivia) says model internals have commoditized. The skill boundary moved up the stack, to the system around the model.

The three labs

What each one shows

Lab 1

Weight map

Five domains ranked 27% → 15%. The narrow spread means no optional domains; the ranking means orchestration judgment is the headline skill.

Signal
Study hours should split proportionally — a 27% domain earns roughly double a 15% domain's time.
Lab 2

Scenario sampler

Draws 4 of the 6 production scenarios with a seeded RNG, then shows which domains that sitting exercises — some draws leave a domain untested.

Signal
The scenario list is the vendor's model of your job site. Build one small project per scenario shape and you've covered the exam's world.
Lab 3

Self-assessment

Ten judgment-call questions, two per domain, scored per domain — then a study budget that doubles your weakest domain's weight.

Signal
Use any blueprint as a rubric even if you never sit the exam. The domain where you hesitate is where the questions would find you.

Architecture

How the demo is built

LayerBehaviorEvidence
Blueprint data + engineDomains, scenarios, exclusions; scenario draw, coverage, study-budget, and scoring math. Pure ES module shared by browser, CLI, and tests.public/blueprint.mjs
Assessment itemsTen scenario-style judgment questions, two per domain, each with a rationale.public/questions.mjs

ServerZero-dependency static host plus /health and /version. No build step.app/server.js

Run locally

Inspect the evidence

npm test         # blueprint math + assessment scoring + server
npm run report   # CLI: weights, seeded draw, scored sample assessment
npm run check    # both
npm start        # serve the lab on :3000

Everything runs in your browser or the CLI — nothing is uploaded anywhere.

Limits

What this demo does not claim

  • Weights and scenario names come from the public exam guide — an unofficial summary, not Anthropic documentation.
  • The 10 questions are judgment-style approximations, not real exam items; a high score here is not a pass prediction.
  • The exam is currently gated to Claude Partner Network member organizations — the blueprint is the usable artifact for everyone else.
  • A blueprint is a proxy signal. It shows what cert-makers decided to test, not what your specific job demands.
